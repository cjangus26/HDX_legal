# HDX legal

Public legal pages for the **HDX Inspect** app.

- [`index.html`](index.html) — Privacy Policy (served via GitHub Pages).

Once GitHub Pages is enabled (Settings → Pages → Deploy from a branch → `main` /
root), the policy is live at the URL shown in that Settings panel — typically
`https://cjangus26.github.io/hdx_legal/`. That URL goes into App Store Connect
as the app's Privacy Policy URL.
