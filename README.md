# HDX legal

Public legal pages for the **HDX Inspect** app.

- [`index.html`](index.html) — Privacy Policy (served via GitHub Pages).

Once GitHub Pages is enabled (Settings → Pages → Deploy from a branch → `main` /
root), the policy is live at the URL shown in that Settings panel:
`https://cjangus26.github.io/HDX_legal/` (a project site's path is the
repository name in its canonical casing). That URL goes into App Store Connect
as the app's Privacy Policy URL and is what the app links from Settings → About
and the first-run screen.
